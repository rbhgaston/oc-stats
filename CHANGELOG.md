# Changelog

## 0.2.0 — 2026-11-07

### Added

- Session sidebar **Stats** panel, ordered local to global: session cost and tokens, project
  cost, then range totals, tools, streak and a daily-steps sparkline.
- `24h` range alongside `7d`, `30d`, `90d` and `all`.
- **Spend** bar splitting a session's cost by output, billed input and cached tokens.
- Hover a model in **Top models** to see its full name; click to pin it.
- SVG previews for the README, generated by `docs/generate-preview.py`.
- `tsconfig.json` and `npm run typecheck` for contributors.

### Changed

- Slash command renamed from `/stats` to `/oc_stats`.
- npm package renamed to `oc-stats-tui`.
- README rewritten with a comparison against the built-in `opencode stats`.
- Sidebar, project and range sections now use colored rules.
- Text colors now use the supported `style` prop on spans, so section and bar colors render.

## 0.1.0 — 2026-11-07

- Initial release: **Overview**, **Projects** and **Performance** tabs.
